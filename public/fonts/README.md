# الخطوط

- `NotoNaskhArabic-Regular.ttf` و`NotoNaskhArabic-Bold.ttf`: خط احتياطي مفتوح المصدر (SIL OFL) لضمان ظهور عربي جميل إذا لم يتوفر Qumra.
- لتفعيل خط **Qumra / Qomra Arabic** (خط تجاري من iwantype)، ضع نسختك المرخّصة هنا بأحد الأسماء:
  - `Qumra.woff2`
  - `Qumra.otf`
  - `Qumra.ttf`
  - أو `Qomra.woff2` / `Qomra.otf` / `Qomra.ttf`

الخط مُعرّف في `public/styles.css` تحت `@font-face` باسم `Qumra`، وسيُستخدم تلقائياً إذا وُجد الملف أو إذا كان الخط مثبتاً على جهاز المتصفح.
